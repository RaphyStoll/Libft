Libft

A custom C library built for the 42 curriculum.

What is included

  • Character classification and conversion helpers
  • String and memory utilities
  • Dynamic allocation helpers
  • File descriptor output helpers
  • Singly linked list helpers

Build

make

Builds both the static and shared libraries:

  • libft.a
  • libft.dylib on macOS
  • libft.so on Linux

Bonus

make bonus

Documentation

Generate the local Doxygen documentation:

make docs

The generated documentation is published on GitHub Pages from the gh-pages branch after each push to main.

GitHub Pages setup

After the workflow runs successfully, enable GitHub Pages in your repository settings and select:

  • Source: Deploy from a branch
  • Branch: gh-pages
  • Folder: /(root)

Usage

Include the header in your project:

#include "libft.h"
libft.h

Then link against the library that fits your target platform.
